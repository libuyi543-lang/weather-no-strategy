# Grok 事件驱动双桶回测

生成范围：2026-07-24 至 2026-07-25

> 研究模式。只使用每个判断时点前已经抓取的数据；Grok 输入不包含最终结算。7月24日的雷达、卫星和周边站完整数据从当地14:36后才可用。

## 方法

- 数据：Ridge V2、Meteoblue、ECMWF、METAR/SPECI、RainViewer、Himawari、周边及上风向站和当时盘口。
- 触发：天气状态有实质变化、Ridge 正常路径不超过三个档，并存在有深度的相邻双桶。
- Grok 输出：`WAIT`、`PAIR_CONVERGING` 或 `PAIR_LOCKED`。
- `PAIR_LOCKED` 要求所有正常和合理备选路径都落在两个相邻桶，逃出双桶只剩异常尾部。
- 交易：每桶5 shares，按5分钟后的真实订单簿VWAP成交；双桶合计价格必须严格低于1。
- 账户：初始20 USDC，始终保留5 USDC现金。

## 结果

| 指标 | 结果 |
|---|---:|
| Grok判断次数 | 35 |
| WAIT | 5 |
| PAIR_CONVERGING | 16 |
| PAIR_LOCKED | 14 |
| 双桶覆盖正式结果 | 14/14，100% |
| 5分钟后仍有正价差 | 1/14 |
| 实际Paper成交 | 1 |
| PnL | +0.55 USDC |
| 账户权益 | 20.00 -> 20.55 USDC |

唯一成交是7月25日北京：Grok在当地14:10锁定 `31°C / 32°C`，5分钟后两桶合计VWAP为0.89，最终结算31°C，投入4.45 USDC，盈利0.55 USDC。

其余13次虽然双桶全部覆盖正确结果，但锁定后合计VWAP都在1附近或以上，不能转化为盈利交易。

## 延迟敏感性

| 执行延迟 | 可成交笔数 | PnL |
|---|---:|---:|
| 0分钟 | 5 | +0.8650 USDC |
| 5分钟 | 1 | +0.5500 USDC |
| 10分钟 | 2 | +0.7533 USDC |
| 15分钟 | 1 | +0.4000 USDC |

盘口机会持续时间很短，交易数随延迟明显变化。不能把双桶预测准确等同于稳定利润。

## 结论

完整系统在现有两天样本中表现出很强的双桶压缩能力，但绝大多数时候市场在AI确认前已经完成定价。事件驱动优于固定14点入场，不过目前只证明“偶尔存在短暂价差”，尚未证明可扩展的稳定收益。

至少需要30个独立结算日，重点跟踪首次锁定时间、双桶合计VWAP、市场首次完成定价时间、执行延迟和区间外错误率。
